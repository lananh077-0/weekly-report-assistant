Weekly Report Assistant

A simple way to turn scattered work updates into a clear, structured weekly report.

In one sentenceEvery Friday, the assistant gathers team updates, project data, meeting notes, and daily work snippets—then drafts a report for your review.

What it does

The Weekly Report Assistant is an AI agent that works like an administrative partner. It collects the week’s updates, groups them by project, and prepares a consistent report in a shared document.

You stay in control of the decisions. The assistant takes care of the repetitive work of searching through chats, checking project updates, and formatting the report.

How it works

  1. Find chat updates that mention completed or delivered work.
  2. Read project tracker rows updated during the week.
  3. Collect meeting decisions, action items, and owners.
  4. Group updates by project and separate results from plans.
  5. Check details against the project tracker as the source of truth.
  6. Draft the report, create a shared document, and provide its link.

What comes out

The assistant creates a shared document with four familiar sections:

📊 This week’s resultsCompleted work, grouped by project
📅 Next week’s planWork that is underway or coming next
⚠️ ChallengesBlockers and possible next steps
📎 Links and sourcesMeeting notes, trackers, and references

What it can and cannot do

✓ It can

  • Collect work updates from connected chats
  • Read project tracker data
  • Summarize meetings and follow-ups
  • Organize updates and draft a report

× It cannot

  • Make up progress that was never reported
  • Change the original project tracker
  • Replace a manager’s judgment
  • Share an unreviewed draft with others

How to start

Send a message to the Weekly Report Assistant in Lark:

Generate my weekly report

Or schedule it to run every Friday at 5:00 PM.

A few things to keep in mind

  • Review the draft before using or sharing it.
  • Set up project tracking fields before connecting the assistant.
  • Messages from WeChat are not connected in this version.
  • The assistant is not designed to make sensitive personnel decisions.
